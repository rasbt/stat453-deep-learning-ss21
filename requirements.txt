# Core requirements to run the notebooks and helper scripts in this repo.

#
# torch/torchvision are pinned to a CUDA 12.4 build via the extra index below,
# matching an NVIDIA driver of 550.x+ (check `nvidia-smi`, top-right "CUDA
# Version"). If your driver supports a different CUDA version, swap cu124 for
# the matching tag from https://pytorch.org/get-started/locally/ (e.g. cu121,
# cu118), or drop the --extra-index-url line entirely for a CPU-only build.
# A plain `torch` install without this pin can silently resolve to a newer
# CUDA build than your driver supports (a "CUDA driver too old" error at
# runtime, not install time) -- see README "Known issues".
#

#   pip install -r requirements.txt
